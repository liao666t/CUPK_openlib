第一章 函数与极限

本章主要介绍了函数的基本概念、极限的定义与性质，以及连续函数的特性。

重点公式：

  • 极限的运算法则：若lim f(x)=A, lim g(x)=B，则lim [f(x)±g(x)]=A±B
  • 两个重要极限：lim(x→0) sinx/x=1, lim(x→∞) (1+1/x)^x=e
  • 夹逼准则：若f(x)≤g(x)≤h(x)且lim f(x)=lim h(x)=A，则lim g(x)=A

第二章 导数与微分

导数是微分学的核心概念，本章详细讲解了导数的定义、几何意义以及各种求导法则。

常用求导公式：

  • (x^n)' = nx^(n-1)
  • (sinx)' = cosx, (cosx)' = -sinx
  • (e^x)' = e^x, (lnx)' = 1/x
  • (a^x)' = a^x·lna, (log_a x)' = 1/(x·lna)

求导法则：

  • [u±v]' = u'±v'
  • [u·v]' = u'v + uv'
  • [u/v]' = (u'v - uv')/v²
  • 链式法则：dy/dx = dy/du · du/dx

第三章 微分中值定理

费马定理、罗尔定理、拉格朗日中值定理、柯西中值定理构成了微分学的基本定理体系。

  • 费马定理：若f(x)在x₀处取得极值且可导，则f'(x₀)=0
  • 罗尔定理：若f(x)在[a,b]连续，在(a,b)可导且f(a)=f(b)，则∃ξ∈(a,b)使f'(ξ)=0
  • 拉格朗日中值定理：若f(x)在[a,b]连续，在(a,b)可导，则∃ξ∈(a,b)使f'(ξ)=[f(b)-f(a)]/(b-a)

第四章 不定积分

不定积分是求导的逆运算，本章总结了换元积分法和分部积分法两大基本技巧。

基本积分公式：

  • ∫x^n dx = x^(n+1)/(n+1) + C (n≠-1)
  • ∫1/x dx = ln|x| + C
  • ∫e^x dx = e^x + C
  • ∫sinx dx = -cosx + C, ∫cosx dx = sinx + C

换元积分法：

第一换元法（凑微分法）：∫f(g(x))g'(x)dx = ∫f(u)du, u=g(x)

第二换元法：令x=φ(t)，将复杂积分化为简单积分

第五章 定积分

定积分的几何意义是曲边梯形的面积，微积分基本定理建立了定积分与原函数的联系。

  • 牛顿-莱布尼茨公式：∫[a,b]f(x)dx = F(b) - F(a)，其中F'(x)=f(x)
  • 定积分分部积分法：∫[a,b]uv'dx = [uv]|(a,b) - ∫[a,b]u'vdx
